## ⚠️ Key Takeaways
- Luôn dùng `===` thay vì `==`
- Luôn dùng `"use strict"`
- Tránh `var`, dùng `let`/`const`
- `typeof null === "object"` là bug lịch sử
- Empty array `[]` là truthy
