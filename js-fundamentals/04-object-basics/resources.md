## ⚠️ Key Takeaways
- Object là reference type, `===` so sánh địa chỉ
- `...spread` chỉ shallow copy
- `this` phụ thuộc cách gọi hàm, arrow function không có `this` riêng
- Luôn dùng `?.` khi truy xuất object có thể null/undefined
- Symbol keys bị ẩn khỏi `Object.keys()` và `for...in`
